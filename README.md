# DeepDir-Visualizer 📂📊

当面对嵌套极深、文件繁杂的庞大数据集或代码库时，想要快速理清目录结构和文件分布往往让人头疼。

**DeepDir-Visualizer** 是一个轻量级的 Python 自动化脚本。它不仅能深度遍历任何复杂的文件夹并提取所有层级的文件名，输出优雅的树状结构报告，还能自动分析文件分布密度，生成直观的数据可视化图表。

## ✨ 核心特性

- **树状结构映射**：递归穿透所有子文件夹，生成层级分明、带有统计数量的 ASCII 目录树报告。
- **自动化可视化**：自动统计每个文件夹内的文件总数，并生成高清柱状图（`.png`），让你一眼看出数据最密集的核心目录（Top 15）。
- **相对路径处理**：图表中智能使用相对路径，避免系统绝对路径过长导致的排版混乱。
